# Portfolio Website

A personal portfolio website built with HTML, CSS, and JavaScript.

## Files

- `index.html` - main portfolio page structure
- `style.css` - styling and theme support for light/dark mode
- `script.js` - interactive behavior and navigation logic
- `assets/` - project assets and certificates

## Usage

Open `index.html` in your browser to view the portfolio.

## Notes

This project is designed as a static web portfolio and does not require a backend.

If you want to deploy it, you can use GitHub Pages or any static hosting service.
